A second-hand listing needs to be matched to one product in a price-comparison catalogue,
so that product's new price can be used as a reference.

Listing title: $title

Candidate catalogue products:
$candidates

Choose the candidate that is **the same product** as the listing. Rules:

- Same manufacturer model. A different generation or suffix is NOT the same product
  (GSB 18-2-LI is not GSB 185-LI; Deore XT M8000 is not M8100).
- A multi-tool set, kit or bundle is NOT the same product as the single tool inside it.
- An accessory (case, sleeve, bag, screen protector, battery, charger) is never the match.
- A different variant of the family is not a match unless the listing asked for it
  (iPhone 13 is not iPhone 13 mini; Galaxy S10 is not Galaxy Tab S10).
- Storage size, colour and condition in the listing are not reasons to reject a candidate.

If none of them is the same product, answer with index -1. Declining is the correct answer
far more often than a loose match is: a wrong match produces a confidently wrong price,
which is worse than no price at all.

Answer with JSON only:
{"index": <0-based index, or -1 for none>, "confidence": <0.0-1.0>, "reason": "<short>"}
