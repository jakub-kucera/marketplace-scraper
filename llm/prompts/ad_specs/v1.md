Read the hardware specifications out of this Czech classified ad. The listing is free text —
nothing in it is structured — so every value you return is something you inferred from prose.

Title: $title
Description: $description

Return only keys you are confident about, and omit everything else. Do not include a key with
a null, empty or guessed value: an absent key means "the ad does not say", which is a useful
answer. A wrong value is far worse than a missing one, because it will be treated as fact.

Recognised keys, all optional:

- `brand` — manufacturer, lowercase (e.g. "apple", "lenovo", "makita")
- `model` — the model designation as the ad gives it (e.g. "MacBook Pro 14", "ThinkPad T480")
- `model_code` — a manufacturer part code if one appears (e.g. "DHP484Z", "A2442")
- `year` — model year as an integer, only if the ad states it
- `cpu` — processor as stated (e.g. "M1 Pro", "i5-10400F", "Ryzen 5 5600X")
- `ram_gb` — integer gigabytes of memory
- `storage_gb` — integer gigabytes of primary storage; convert TB to GB (1 TB = 1024)
- `storage_type` — "ssd", "hdd" or "nvme"
- `gpu` — graphics card as stated (e.g. "RTX 3060 Ti", "RX 6700 XT")
- `screen_inches` — number, e.g. 14 or 15.6
- `condition` — one of "new", "like_new", "used", "damaged"

Rules that decide the hard cases:

- **Storage and memory are routinely confused in Czech ads.** "16/512" on a laptop means
  16 GB RAM and 512 GB storage; "512GB" alone on a phone is storage. If which one is meant is
  genuinely ambiguous, omit both.
- A number in the title that is part of the model name is not a spec. "iPhone 13" is a model,
  not 13 GB of anything; "ThinkPad T14" is not a 14-inch claim unless the ad says so
  separately.
- Words like "vada", "rozbité", "na díly", "nefunkční", "praskl" mean `condition: "damaged"`,
  whatever else the ad claims.
- The price is never a spec.
- If the listing is not hardware at all (clothing, furniture, a service), return an empty
  object. That is the correct answer, not a failure.

Answer with JSON only, for example:
{"brand": "apple", "model": "MacBook Pro 14", "cpu": "M1 Pro", "ram_gb": 16, "storage_gb": 512, "condition": "used"}
